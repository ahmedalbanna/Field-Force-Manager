# **App Name**: Field Force Manager

## Core Features:

- Dashboard Overview: Dashboard with key metrics and upcoming visits, providing an at-a-glance view of daily/weekly tasks.
- Visit Plan Calendar: Calendar view to display scheduled visit plans.
- Client Management: Client list with search and filtering capabilities, allowing representatives to quickly find and manage their assigned clients.
- Promotional Material Access: Browse and view promotional materials such as catalogs and brochures.
- Product Catalog: Product catalog with search functionality and pricing.
- Geolocation Check-in: Capture representative location upon visit check-in, facilitating visit verification.
- AI-Suggested Next Steps: Generate suggested next steps for a visit completion form. The AI tool may use available client details to determine the best proposal.

## Style Guidelines:

- Primary color: A professional, trustworthy blue (#29ABE2), to instill confidence and reliability.
- Background color: Light gray (#F0F2F5), offering a clean and unobtrusive backdrop.
- Accent color: A vibrant orange (#FF8C00) to highlight key actions and calls to action.
- Body text: 'PT Sans', sans-serif, for body text as it offers a modern yet warm and accessible feel for readability on various devices.
- Headline font: 'Space Grotesk', sans-serif, to give a tech-oriented modern look.
- Use consistent, modern line icons to represent various functions and data points, ensuring clarity and easy recognition.
- Maintain a clean and intuitive layout, ensuring key information and actions are easily accessible.
